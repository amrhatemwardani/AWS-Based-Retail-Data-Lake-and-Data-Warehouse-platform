# Data Formats Documentation

## Dataset
We use the Olist Brazilian E-Commerce dataset.

## CSV
The original dataset files are provided in CSV format.

## JSON
The customers dataset will be converted from CSV to JSON.

JSON is useful for structured records and exchanging data between applications.

## Parquet
The products dataset will be converted from CSV to Parquet.

Parquet is useful for analytical workloads and efficient data storage.

## Objective
The project demonstrates the use of CSV, JSON, and Parquet formats.
